# ActionForge Writer — Tester Release v1

**Status:** READY FOR PROTECTED PREVIEW TESTING

## Required tester tasks
1. Business/customer email.
2. Short text message.
3. Doctor/office message with an 800-character limit.
4. Message containing locked names/dates/prices or commitments.
5. Rewrite requiring a warmer or stronger tone without changing facts.

## Acceptance evidence
For each task record:
- Facts preserved? YES/NO
- Required points retained? YES/NO
- Avoided points excluded? YES/NO
- Requested word/character limit met? YES/NO
- Next action clear? YES/NO
- Ready to send: YES / MINOR EDIT / NO

## Release thresholds
- 100% preservation of explicitly locked facts in deterministic cases.
- >=95% hard character-limit compliance after final validation.
- >=90% tester rating: ready to send with no or minor edits.
- No critical mobile/accessibility issue.
- No autonomous sending.

## Governance
Protected preview testing only. No public release, autonomous sending, or external commitment is authorized.
