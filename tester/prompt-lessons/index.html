Lesson 1: How to Get Better Answers from AI

Important Note About the Tester Version

People who participate at that level will continue receiving lessons at no cost. If someone prefers not to provide feedback or follow the process, the system will still be available later as a paid product.

Core idea

Most people think AI works like Google. It does not. AI works more like a helper waiting for instructions.

If you give weak instructions, you get weak results. If you give clear instructions, results improve immediately.

What most people do

  • "Rewrite this"
  • "Help me with an email"
  • "What should I do?"

AI answers, but the response often feels generic, shallow, or not quite right. The problem is usually that the instruction was too vague.

Try this

  1. Use AI for any task.
  2. Add one clear instruction.
  3. Notice whether the answer improves.

Feedback questions

  1. What task did you try with AI?
  2. What extra instruction did you add?
  3. Did the answer improve? If yes, how?
  4. Was anything unclear?

Lesson 2: The Two Lines That Change Everything

From this point forward, always end your prompts with these two lines:

Enhance this prompt.
Refine this prompt.

Enhance means add what is missing: helpful context, structure, roles, or examples.

Refine means tighten what is there: clearer wording, less ambiguity, and better focus.

Used together, they tell AI: First make this better - then make it precise.

Try this

  1. Use AI for any task.
  2. End the prompt with the two lines above.
  3. Notice the difference.

Feedback questions

  1. What did you ask AI to do?
  2. Did you add both lines?
  3. What changed in the answer?
  4. Was the rule clear?

Lesson 3: Start With the Instruction

AI works best when it sees what you want it to do before it sees details.

When possible, start with the instruction first, then add any background or content underneath.

Here is what I want - now here is what it applies to.

Example

Help me write a calm, friendly reply.

Here is the situation: my friend is upset about a schedule change, and I do not want to sound harsh.

Enhance this prompt.
Refine this prompt.

Feedback questions

  1. Did starting with the instruction make the prompt easier?
  2. What instruction did you start with?
  3. Did you use Enhance/Refine?

Lesson 4: Tell AI How You Want the Answer

If you care about how the answer looks, say so.

A few words like "bullet points," "short paragraph," or "plain English" often make a big difference.

You are not being picky - you are being clear.

Helpful habit: use a short example

If you want a certain style or type of answer, showing a short example often works faster than explaining it.

Write this in a similar style to the example below.

Feedback questions

  1. What format did you ask for?
  2. Did the answer become easier to use?
  3. Would a short example have helped?

Lesson 5: When Answers Feel Shallow

Sometimes AI gives an answer that is technically okay but not very useful. Often that happens because AI does not have enough context.

Adding a role, such as "act as a reviewer" or "act as a planner," often improves results - especially before you apply the enhance/refine rule.

Context can include

  • Who the answer is for
  • What the goal is
  • What tone you want
  • What problem you are trying to solve
  • A short example or reference

Feedback questions

  1. What context did you add?
  2. Did the response become less shallow?
  3. What role, if any, did you give AI?

Lesson 6: Is This Real News or Just Marketing?

This lesson shows you how to use AI to quickly evaluate a long article without reading every word.

The prompt to use

You are an objective analyst.
Review the following article and determine whether it is primarily:
(1) a marketing or promotional piece, or
(2) a legitimate news or informational article.

If it is primarily marketing, briefly explain why.

If it is a legitimate news or informational article, extract the key facts and list them in order of importance, with the most important first.

Keep the analysis factual, neutral, and concise.

Enhance this prompt.
Refine this prompt.

Then paste the article below it.

Important: AI can sound confident even when it is wrong. Treat AI as a fast assistant, not a final authority.

Feedback questions

  1. What article did you test?
  2. Was it mostly marketing or useful information?
  3. Did AI identify the key facts clearly?

Lesson 7: Turn Useful Prompts Into Reusable Tools

Good prompts are rarely perfect the first time. Trying a prompt, adjusting it, and reusing it later is how this is meant to work.

When you get a prompt that works well, save it. Over time, you will build a small library of prompts you can reuse instead of starting from scratch.

That is when AI stops being a novelty and starts saving real time.

Feedback questions

  1. Which prompt from this course would you save?
  2. What would you name it?
  3. Where would you store it?

Lesson 8: Let AI Build the Prompt for You

This is the capstone lesson. It removes the last common frustration people have with AI:

Am I wording this correctly?

You can first ask AI to design the instructions for the task. You become the director. AI becomes the prompt designer.

The prompt that builds a prompt

You are an expert prompt designer.
I want to accomplish the following task:
[briefly describe what you want to do].

Please create a clear, well-structured prompt that I can use to get the best possible result.

If important information is missing, identify it or make reasonable assumptions.

Present the final prompt in a ready-to-use form.

Enhance this prompt.
Refine this prompt.

Feedback questions

  1. What task did you use the prompt-builder for?
  2. Did AI create a better prompt than you would have written?
  3. Which lesson helped you most?
  4. What should be changed before this system is sold?
